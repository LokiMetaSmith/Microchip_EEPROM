## Archived: 2026-10-31

* Repository Context: This repository contains the `Microchip_EEPROM` Arduino library.
* Purpose: Implements the Microchip UNI/O OneWire interface for Microchip EEPROM devices, based on Falke88's code.
* Testing: Tested on Microchip 11AA160 EEPROM.
* Notes: For 11LC141 and 11AA161 versions, change `UNIO_device_address` to 0xA1.
* Dependencies: Requires the `TimerOne` Arduino library.
